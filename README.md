# JavaScript

This repository contains solutions for the **JavaScript Problem Solving Roadmap Assignment**.  
The tasks are designed to improve problem-solving skills and understanding of core to advanced JavaScript concepts.

---

# Topics Covered

- String Manipulation
- Arrays & Loops
- Conditional Statements
- Higher-Order Functions
- Data Structures
- Algorithms
- Closures
- Memoization
- Asynchronous JavaScript
- Promises & Fetch API

---

# Tasks Included

## Easy Level: Warm-ups & Core Syntax

### Task 01 - Reverse a String
Reverse a given string using string methods and loops.

### Task 02 - FizzBuzz Scenario
Print numbers with Fizz/Buzz replacements based on divisibility rules.

### Task 03 - Find the Largest Number
Find the maximum number from an array.

---

## Basic to Intermediate Level: Data Structures & Logic

### Task 04 - Count Vowels
Count total vowels in a string while ignoring capitalization.

### Task 05 - Remove Duplicates from Array
Remove repeated values and return unique elements only.

### Task 06 - Check for Palindrome
Check whether a string reads the same forwards and backwards.

### Task 07 - Title Case a Sentence
Capitalize the first letter of every word in a sentence.

---

## Advanced Level: Closures, Async & Algorithms

### Task 08 - Two Sum Algorithm
Find indices of two numbers whose sum equals the target value.

### Task 09 - Memoized Function Decorator
Implement memoization using closures and caching techniques.

### Task 10 - Asynchronous Fetch Timeout Wrapper
Create a fetch utility with timeout handling using Promise.race().
